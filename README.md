# 🌦️ Weather Forecast Application

A responsive weather application that provides real-time weather information and a 5-day forecast for cities around the world using the OpenWeather API.

## 📌 About the Project

The Weather Forecast Application is a web-based project developed using HTML, CSS, and JavaScript. It allows users to check current weather conditions by searching for a city or detecting their current location.

The application displays important weather information, including temperature, weather conditions, humidity, wind speed, and feels-like temperature. It also provides a 5-day forecast and allows users to switch between Celsius and Fahrenheit.

## ✨ Features

- 🌍 Search weather by city name.
- 📍 Detect current location using Geolocation.
- 🌡️ Switch between Celsius and Fahrenheit.
- ☁️ Display current weather conditions.
- 📅 View a 5-day weather forecast.
- 💧 Display humidity levels.
- 💨 Display wind speed.
- 🌡️ Show feels-like temperature.
- 🎨 Dynamic backgrounds based on weather conditions.
- 📱 Responsive design for mobile and desktop.

## 🛠️ Technologies Used

- **HTML5** – Application structure.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Application logic and API integration.
- **OpenWeather API** – Weather data and forecasts.
- **Fetch API** – Fetching data from external APIs.
- **Geolocation API** – Detecting the user's current location.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project

Open the downloaded folder in Visual Studio Code.

### 3. Configure the API

Create an API key through [OpenWeather](https://openweathermap.org/api).

Configure the API key securely in your application. Do not commit secret API keys to GitHub.

### 4. Run the Application

Use the Live Server extension in Visual Studio Code to open `index.html` in your browser.
